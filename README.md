## 🌐 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/capotejeverlyshane/My_CV_V2.git
   cd My_CV_V2
   ```

2. **Open in browser:**
   * Simply double-click `index.html` or open it with any web browser.
   * Or use VS Code Live Server extension: right-click `index.html` > *Open with Live Server*.

---

## ☁️ Vercel Deployment

1. Log in to [Vercel](https://vercel.com/) with GitHub.
2. Select your repository: `capotejeverlyshane/My_CV_V2`.
3. Set Framework Preset to **Other** (Static HTML).
4. Click **Deploy**.
